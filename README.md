# Data Professional Survey Analysis – Power BI

## Project Overview

This project analyzes survey responses from data professionals to understand their salaries, job roles, programming language preferences, career-switch experiences, and job satisfaction.

## Dataset

* 630 survey responses
* 28 columns
* Contains information about job roles, salary ranges, demographics, education, and professional experiences.

## Data Cleaning & Transformation

Performed data cleaning and transformation using Power Query:

* Removed unnecessary columns.
* Changed column data types.
* Handled missing and null values.
* Split and transformed columns for better analysis.

## Dashboard Highlights

The interactive Power BI dashboard explores:

* Total number of survey participants.
* Average age of respondents.
* Average salary by job title.
* Favourite programming languages.
* Difficulty of entering the data profession.
* Satisfaction with salary and work-life balance.
* Country-wise distribution of respondents.
